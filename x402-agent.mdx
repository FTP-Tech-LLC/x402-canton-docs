Pay from the CLI, from code, or give an AI agent a wallet over MCP. The CLI, code and local MCP wallets are self-custody; FTP's facilitator relays each payment and pays the network fee.

## CLI

```bash
npm i -g @ftptech/canton-agent-wallet
canton-agent-wallet create --relay-url https://facilitator.ftptech.xyz
canton-agent-wallet pay --max 0.5 https://api.example.com/resource
```

A new wallet gets a 0.2 CC starter grant. To add more, send CC to `canton-agent-wallet address` and run `canton-agent-wallet claim`. Creating a wallet accepts the [Terms of Service](/terms).

`--max` caps one payment and `--pay-to <party>` pins the payee. Without them `pay` pays whatever the 402 asks.

## Code

```typescript
import { makePayingFetch } from "@ftptech/canton-agent-wallet";

const payFetch = await makePayingFetch({
  relayUrl: "https://facilitator.ftptech.xyz",
  network: "canton:mainnet",
  maxPaymentValue: "0.5", // CC per payment
});

const res = await payFetch("https://api.example.com/resource"); // 402 is paid and retried
```

It works like `fetch`, POST bodies included. `expectedPayTo` pins the payee; `maxPaymentValueByInstrument` caps a token.

## MCP

**Hosted.** Connect `https://pay.ftptech.xyz/mcp` as a custom connector in Claude, ChatGPT (developer mode) or Perplexity and sign in with a passkey. FTP holds the wallet for you; limits default to 5 CC per payment and 20 CC per day. Steps: [ftptech.xyz/mcp](https://www.ftptech.xyz/mcp).

**Local, self-custody:**

```bash
claude mcp add canton-x402 -- npx -y @ftptech/canton-x402-mcp \
  --relay-url https://facilitator.ftptech.xyz \
  --allow-domains api.example.com \
  --max-per-tx 1 --daily-cap 2
```

The flags are the spend policy and the agent cannot change them. Without `--allow-domains` every payment is refused. Tools: `get_address`, `get_balance`, `request_funding`, `claim`, `pay`, `withdraw`, `swap`.

## Tokens

Paying in a token needs your consent:

```bash
export CANTON_AGENT_PAYABLE_INSTRUMENTS="decentralized-usdc-interchain-rep::12208115f1e168dd7e792320be9c4ca720c751a02a3053c7606e1c1cd3dad9bf60ef|USDCx"
canton-agent-wallet pay --asset USDCx --max 1 https://api.example.com/resource
```

To receive a token, create its preapproval once: `canton-agent-wallet preapproval --admin <registrar> --id USDCx`. Registrars are in [MainNet values](/x402-payments#mainnet-values).

## Commands

| Command | Does |
|---|---|
| `create --relay-url <url>` | Create the wallet (once) |
| `address` | Your party id, to receive funds |
| `balance` | Holdings of every token |
| `claim` | Accept incoming transfers |
| `pay [--max <n>] [--pay-to <party>] [--asset <SYM>] <url>` | Fetch a URL and pay its 402 |
| `withdraw --to <party> --amount <n>` | Send CC, or a token with `--admin` and `--id`. Without `--amount` it sends everything |
| `swap --in CC --out USDCx --amount <n>` | Swap CC and a registry token |
| `export` / `import` | Back up or restore the key |

All commands and options: [agent-wallet README](https://github.com/FTP-Tech-LLC/x402-canton-agent/tree/main/packages/agent-wallet).

## Good to know

- **The key is the money.** It lives in `~/.canton-agent/wallet.json`. Back it up with `export`.
- **Do not retry a payment in a loop.** After a timeout or error, check `balance` first: the payment may have gone through.
- **Behind a proxy**, set `HTTPS_PROXY` for the CLI.

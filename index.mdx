---
title: "x402 on Canton"
description: "Pay per HTTP request in Canton Coin or a CIP-56 token. No API keys, no accounts: the payment is the credential."
---

An endpoint answers `402 Payment Required`, the client pays on Canton in Canton Coin or a CIP-56 token such as USDCx, and the retried request goes through. No API keys, no billing accounts.

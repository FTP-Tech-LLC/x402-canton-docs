---
title: "x402 on Canton"
description: "Pay per HTTP request in Canton Coin or a CIP-56 token. No API keys, no accounts; the payment is the credential."
---

x402 brings the `402 Payment Required` HTTP standard to Canton Network. A client calls an endpoint, gets a `402` with payment requirements, pays on-ledger in Canton Coin or a CIP-56 registry token (e.g. USDCx), and retries. The payment is the credential: no API keys, no billing accounts.

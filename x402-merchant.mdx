---
title: "Merchant integration"
description: "Charge per request in Canton Coin or a CIP-56 token on Express or Next.js."
---

Callers pay before your handler runs. FTP's facilitator settles each payment and pays the network fee; you only receive.

## Quickstart

<Steps>
<Step title="Create a wallet">
```bash
npm i -g @ftptech/canton-agent-wallet
canton-agent-wallet create --relay-url https://facilitator.ftptech.xyz
canton-agent-wallet address   # your party id: use it as payTo
```
Back up the key with `canton-agent-wallet export`. Creating a wallet accepts the [Terms of Service](/terms).
</Step>

<Step title="Turn on receiving">
Send a few CC to your party id, then:
```bash
canton-agent-wallet claim
canton-agent-wallet preapproval
```
The `TransferPreapproval` lets each payment settle to you in one transaction. It lasts 30 days.
</Step>

<Step title="Gate a route">
```bash
npm i @ftptech/x402-canton-express
```
```typescript
import express from "express";
import { cantonPaymentMiddleware } from "@ftptech/x402-canton-express";

// FTP MainNet values, copy as is
const DSO = "DSO::1220b1431ef217342db44d516bb9befde802be7d8899637d290895fa58880f19accc";
const extra = {
  assetTransferMethod: "transfer-factory",
  feePayer: "ftp-x402-infrastructure::1220da867ceb28e1531ebfbea9ca9b25f75be06755999f48f0ec4b96f4174e3cd133",
  synchronizerId: "global-domain::1220b1431ef217342db44d516bb9befde802be7d8899637d290895fa58880f19accc",
  instrumentId: { admin: DSO, id: "Amulet" },
  executeBeforeSeconds: 120,
} as const;

// Your price
const price = {
  scheme: "exact",
  network: "canton:mainnet",
  asset: "CC",
  amount: "100000000", // 0.01 CC (1 CC = 10^10)
  payTo: "<your party id>",
  maxTimeoutSeconds: 120,
  extra,
} as const;

const app = express();
app.use(
  cantonPaymentMiddleware({
    facilitatorUrl: "https://facilitator.ftptech.xyz",
    routes: { "GET /api/data": { accepts: [price] } },
  }),
);
app.get("/api/data", (_req, res) => res.json({ data: "paid" }));
app.listen(3000);
```
</Step>

<Step title="Check">
```bash
curl -i http://localhost:3000/api/data   # 402 with a PAYMENT-REQUIRED header
```
To make a test payment, use a second wallet as in [Agent integration](/x402-agent). Paying yourself is refused.
</Step>
</Steps>

## Next.js

```typescript
// app/api/data/route.ts, with `price` from the Express example
import { withCantonPayment } from "@ftptech/x402-canton-next";

export const GET = withCantonPayment(
  async () => Response.json({ data: "paid" }),
  { accepts: [price], facilitatorUrl: "https://facilitator.ftptech.xyz" },
);
```

## Good to know

- **Keep the preapproval live.** Without it payers get `402 invalid_exact_canton_preapproval_missing`. `preapproval --status` shows the expiry, `preapproval --force` renews early, and `--days 180` buys a longer one (about 0.016 CC per day).
- **Charging USDCx or another token.** Create its preapproval once with `canton-agent-wallet preapproval --admin <registrar> --id USDCx`, and set `asset` and `extra.instrumentId` to the token from [MainNet values](/x402-payments#mainnet-values). Every token uses 10 decimals.
- **More than one instance.** Each payment is served once per process. With several instances, pass a shared store so a payment is served once in total:
  ```typescript
  const redeemed = {
    claim: async (id: string) => (await redis.set(`x402:${id}`, "1", { NX: true, EX: 93600 })) === "OK",
    release: async (id: string) => { await redis.del(`x402:${id}`); },
  };
  cantonPaymentMiddleware({ facilitatorUrl, routes, redeemed });
  ```
- **Header size.** The payment header is 8 to 10 KiB. Every proxy in front of your app must accept 16 KiB: nginx `large_client_header_buffers 4 16k;`, Node `--max-http-header-size=32768`.
- **Settlement runs before your handler.** If your handler fails afterwards, the payer has already paid.
- **Busy wallet.** Every payment adds a holding. Run `canton-agent-wallet merge` now and then.
- **`feePayer` set before 2026-09-29?** Switch it to the value above.
